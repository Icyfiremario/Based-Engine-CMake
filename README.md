# Based Engine

## About
Based Engine is an open source game engine written in C++. It uses glfw for window management to allow support for several rendering APIs.

## Support
### Rendering APIs
- Vulkan
- OpenGL
- DirectX

### Operating Systems
- Windows
- Linux
